Aula de Tabelas 3- Tabelas Grandes


Valores possíveis do scope:
col: Indica que o cabeçalho se aplica a uma coluna.
row: Indica que o cabeçalho se aplica a uma linha.
colgroup: Indica que o cabeçalho se aplica a um grupo de colunas.
rowgroup: Indica que o cabeçalho se aplica a um grupo de linhas.
Ele nao é um efeito visual, é mais como uma forma de organizar a tabela e replicar essa informação para que fique de fácil compreenção.
